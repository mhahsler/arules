# Random Samples and Permutations

Provides the generic function `sample()` and methods to sample from
[transactions](http://michael.hahsler.net/arules/reference/transactions-class.md)
and
[associations](http://michael.hahsler.net/arules/reference/associations-class.md).

## Usage

``` r
# S4 method for class 'itemMatrix'
sample(x, size, replace = FALSE, prob = NULL, ...)

# S4 method for class 'associations'
sample(x, size, replace = FALSE, prob = NULL, ...)
```

## Arguments

- x:

  object to be sampled from (a set of
  [associations](http://michael.hahsler.net/arules/reference/associations-class.md)
  or
  [transactions](http://michael.hahsler.net/arules/reference/transactions-class.md)).

- size:

  sample size.

- replace:

  a logical. Sample with replacement?

- prob:

  a numeric vector of probability weights.

- ...:

  further arguments.

## Value

An object of the same class as `x`.
